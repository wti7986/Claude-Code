# Jev Typo Checker

顧客に送るメッセージ（ブラウザの入力欄）の誤字・脱字・誤変換を即座に検知し、修正案を提示するブラウザ拡張機能です。

## 仕組み

2段構成のパイプラインになっています。

1. **即時スクリーニング (Jev / TypeSafe AI)** — 入力が止まって少し経つと、文単位で分割し、`Noul`（yes/no の確率判定）で「この文に誤字がありそうか」を1リクエストにまとめて並列に問い合わせます。軽い判定なので高速です。
2. **修正案の生成 (Claude)** — スクリーニングで閾値を超えた文だけ、Claude に「誤字・脱字・誤変換のみを直す」よう指示し、修正後の文と理由を構造化出力（Zod スキーマ）で受け取ります。Jev の System One モデルは確率付きの型付き判定を返す設計で、文章そのものは生成しないため、実際の修正文生成はここで生成系モデルに任せています。

```
extension/  ブラウザ拡張 (Manifest V3)
server/     Node.js + Express のバックエンド
```

拡張機能はテキストを直接 TypeSafe / Anthropic の API キーで叩かず、必ず自前のバックエンド経由で呼び出します（API キーはサーバー側にのみ置く）。

## セットアップ

### 1. バックエンド

```sh
cd server
npm install
cp .env.example .env
# .env に TYPESAFE_API_KEY と ANTHROPIC_API_KEY を設定
npm run dev
```

デフォルトで `http://localhost:3300` で起動します。

### 2. 拡張機能

1. Chrome で `chrome://extensions` を開き、「デベロッパーモード」を有効化
2. 「パッケージ化されていない拡張機能を読み込む」で `extension/` フォルダを選択
3. 拡張機能アイコンをクリックし、バックエンドURL（デフォルト `http://localhost:3300`）を確認・保存

任意のページのテキストエリア / input / contenteditable な入力欄にフォーカスして入力すると、入力が止まってしばらくして右下にパネルが表示され、誤字候補があれば修正案と「この修正を適用」ボタンが出ます。

## 制限・注意点

- **拡張機能は初期状態で `localhost` / `127.0.0.1` のバックエンドにのみアクセスできます。** 別ホストにデプロイする場合は `extension/manifest.json` の `host_permissions` にそのオリジンを追加してください。
- 文の同一性チェックは単純な部分文字列一致です。同じ文がフィールド内に複数回出現する場合、最初に見つかった箇所が置換されます。
- リッチテキストエディタ（Gmail の本文など、書式付き contenteditable）では `innerText` の単純な置換になるため、書式が崩れる可能性があります。プレーンなテキストエリアや input での利用を主眼にしています。
- Jev のスクリーニングと Claude の修正案生成を1リクエストにまとめているため、誤字候補が多い文章では体感の応答が少し遅くなります。真に「即時」のフィードバックが必要な場合は、スクリーニング結果を先に返す2段階レスポンスへの拡張を検討してください。
- `TYPO_FLAG_THRESHOLD`（デフォルト 0.5）で、Jev の確率がどの程度でフラグを立てるかを調整できます。
